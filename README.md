# Customer Behavior Analysis

I built an interactive **Customer Behavior Dashboard** using **SQL, Python, and Power BI**, analyzing customer sales, revenue, subscription status, category-wise performance, and age-group trends. Python and SQL were used for data analysis and preparation, while Power BI was used to create KPIs, interactive slicers, and visual dashboards for business insights.

## Overview

An end-to-end **Data Analytics project** focused on understanding customer behavior, sales performance, and revenue patterns.

The project transforms customer-level data into an interactive Power BI dashboard to analyze customer segments, category performance, subscription status, and age-group trends.

## Dataset

The analysis uses customer-level data containing:

* Customer ID
* Purchase Amount
* Review Rating
* Category
* Subscription Status
* Gender
* Shipping Type
* Age Group

## Tools & Technologies

* **Python** — Data loading, EDA, analysis, and data cleaning
* **SQL / PostgreSQL** — Data querying and analytical analysis
* **Power BI** — Dashboard development, KPIs, visualizations, and interactive filtering
* **Gamma** — Project presentation

## Dashboard

The Power BI dashboard includes:

* **Average Purchase Amount**
* **Average Review Rating**
* **Number of Customers**
* Customer distribution by **Subscription Status**
* **Sales by Category**
* **Revenue by Category**
* **Sales by Age Group**
* **Revenue by Age Group**
* Interactive slicers for:

  * Subscription Status
  * Gender
  * Category
  * Shipping Type

## Key Analysis

The project focuses on answering business questions such as:

* How is the customer base distributed across subscription statuses?
* Which categories generate higher sales and revenue?
* How does revenue vary across age groups?
* How can customer segments be analyzed using gender, category, subscription status, and shipping type?
* How can customer-level data be converted into actionable business insights?

## Results

The final dashboard provides an interactive view of **customer behavior, sales, revenue, and customer segmentation**, allowing users to filter and explore different business segments dynamically.

## How to Run

1. Load the dataset using Python.
2. Perform EDA and data cleaning.
3. Run the required SQL queries in PostgreSQL.
4. Connect the prepared data to Power BI.
5. Open the Power BI `.pbix` file.
6. Use the slicers to interact with the dashboard and analyze different customer segments.
